# Orbit v0.1.0

Orbit의 첫 공개 릴리스입니다. 로컬 AWS CLI의 프로필로 AWS 리소스를 조회하고 관리하는 Windows 데스크톱 앱입니다.

## 다운로드

- **Orbit_0.1.0_x64-setup.exe**: Windows x64 설치 프로그램 (현재 사용자용).
- **Orbit_0.1.0_windows_x64.exe**: 설치 없이 실행하는 단일 EXE.
- **Source code (zip / tar.gz)**: 이 버전의 전체 소스코드.
- **SHA256SUMS.txt**: 두 실행 파일의 SHA-256 체크섬.

## 주요 기능

- EC2, RDS, S3, CloudWatch 리소스 조회, S3 폴더 탐색 및 로그 본문 확인.
- AWS 프로필·리전 전환, 서비스 검색, 즐겨찾기, 컨텍스트 메뉴.
- AWS CLI 모델 기반 API 옵션 입력 폼, 필수값·설명·검증, JSON 편집 및 공식 문서 링크.
- 계정·리전·요청 내용을 검토하고 확인 문구를 입력한 뒤 API 실행. 변경 작업은 세션의 고급 작업 활성화가 필요합니다.
- 선택한 리소스와 연결 관계를 표시하는 인프라 구조도, 자동 배치 및 PNG/PDF 내보내기.
- 한국어·영어, 라이트·다크·시스템 테마, Pretendard 글꼴 및 shadcn 알림.

## 실행 환경

Windows x64, AWS CLI v2 및 Microsoft Edge WebView2 Runtime이 필요합니다. AWS CLI는 표준 Windows 설치 경로 사용을 권장합니다. AWS 인증 정보는 앱에 입력하지 않고 AWS CLI에서 설정합니다. SSO 사용자는 AWS CLI로 로그인한 뒤 실행하세요.

소스 빌드에는 Node.js 22+, Rust/MSVC 빌드 도구가 필요합니다. 빌드 방법은 README를 참고하세요.

## 알려진 제한

- 초기 배포본으로 실행 파일과 설치 프로그램에 Windows 코드 서명이 없습니다. Windows에서 알 수 없는 게시자 경고가 표시될 수 있습니다.
- Windows x64만 배포합니다. 깨끗한 Windows 환경의 설치·업그레이드·제거 검증, 대규모 계정 성능 측정 및 자동 업데이트는 아직 제공하지 않습니다.
- 모든 AWS API를 검증한 것은 아닙니다. 바이너리·스트리밍 API, S3 업로드/다운로드 및 sync는 지원하지 않습니다. API 페이지 이동은 응답 커서를 다음 요청에 입력하는 방식입니다.
- API 옵션 설명은 AWS 모델의 원문 언어로 표시됩니다. AWS IAM 권한과 서비스별 제약은 AWS CLI/AWS에서 검증합니다.
- AWS 요청에는 서비스별 비용이 발생할 수 있습니다. 변경 API는 실행 전 계정·리전·입력 내용을 확인하세요.

## 검증

프런트엔드 회귀 테스트 61개와 Rust 단위 테스트 13개, TypeScript 및 Windows 릴리스 빌드를 통과했습니다. 옵션 폼·JSON 전환·알림 동작을 브라우저에서도 확인했습니다. 검증 과정에서 AWS 리소스를 수정하거나 삭제하지 않았습니다.
